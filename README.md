# NR City Accounting - Responsive Website

A modern, clean, and fully responsive multi-page landing page website for **NR City Accounting**, built using HTML5, CSS3, and JavaScript.

## 🌟 Overview

NR City Accounting provides professional financial, bookkeeping, tax return, and payroll services for individuals, freelancers, and businesses. This project presents a clear, user-friendly layout showcasing company services, client feedback, interactive service modals, and contact channels.

## ✨ Features

- **Modern & Clean UI/UX:** Styled using custom CSS variables, elegant color palettes, and responsive typography.
- **Interactive Service Details Modal:** Dynamic popup overlay displaying detailed breakdowns for each accounting service using pure JavaScript.
- **Fully Responsive Design:** Seamless layout adaptiveness for Desktop, Tablet, and Mobile devices with a collapsible navigation menu.
- **Service Section & Cards:** Grid-based presentation covering Bookkeeping, Accounts Preparation, Company Tax Returns, Self Assessment, VAT Returns, and Payroll.
- **Client Testimonials:** Structured grid highlighting feedback from freelancers and corporate clients.
- **Contact & Booking Form:** Modern call-to-action sections with contact form inputs and direct links for phone, email, and WhatsApp.

## 🛠️ Tech Stack

- **HTML5:** Semantic structural components (`header`, `main`, `section`, `article`, `footer`, `modal`).
- **CSS3:** Flexbox, CSS Grid, Custom Variables, Transitions, and Media Queries.
- **JavaScript (ES6):** Modal popups, event handling, dynamic content rendering, and keyboard accessibility (`Escape` key close).
